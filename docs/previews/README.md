# Station plan alignment preview

`canning-bridge-overlay.png` is a research comparison of the official Canning Bridge station plan with real aerial imagery, created on 24 October 2026. It is not a navigation layer in the application.

The left panel shows aerial imagery and official GTFS stop coordinates. The right panel shows the same imagery with the plan at 50% opacity. Stands 1–3 calibrated translation, rotation and uniform scale; stand 4 was withheld and differed by 14.6 metres. Printed symbols, timetable coordinates and source dates have uncertainty. No nonlinear warping or generated imagery was used.

Plan source: [Transperth Canning Bridge Station PDF](https://www.transperth.wa.gov.au/timetablePDFs/BusStationMaps/Canning%20Bridge%20Station.pdf), current as 5 July 2026. Aerial imagery: Esri World Imagery; credit **Esri, Vantor, Earthstar Geographics and the GIS User Community**. Imagery capture date was not available. Credits are also printed on the comparison.

The preview demonstrates approximate georeferencing and independent accuracy checking. It does not establish survey accuracy, indoor connectivity, platform access or the phone's floor. Production station context uses the separately attributed OpenStreetMap catalog.
